Packages: macOS Apple silicon, Windows x64, Linux amd64, local web Linux x64.

FIX
An existing Core home can contain executable alias symlinks in tmp/arg0.
The 0.2.4 recovery copier refused these aliases and safely kept the old Core,
but consequently could not complete the upgrade on some previously used profiles.
0.2.5 excludes only that regenerated temporary directory from the snapshot.
It does not follow symlinks or delete the original home. History, settings and
neighboring data remain verified; links elsewhere still cause safe rejection.

The corrected updater may retry a previous algorithm's failed activation once.
Repeated failure remains suppressed, including across restarts. A deliberate
rollback is still respected. No permissions or recovery integrity checks are
disabled. Update existing 0.2.4 clients to this application version.

AUTOMATIC CORE UPDATES
Internal GitLab discovers, qualifies and publishes independently for each target
every six hours, without requiring a personal Mac or Windows PC to stay online.
After this one-time Synora upgrade, the signed v2 Core channel is checked about
30 seconds after launch and every six hours. Automatic updates are on by default;
an explicit user preference disabling them is preserved.
Exact official archive hashes and complete inventories are verified. Native
version, initialize, settings and history APIs are checked locally before an
idle-only switch. Old Core and its data are retained for recovery.
Core 0.154.0 and recovery 0.153.4 are bundled; 0.155.0 is available through the
signed channel. Core auto-update is separate from updating the Synora app itself.

INSTALLATION
macOS: extract the ARM64 ZIP and replace the application. macOS 13+ and Apple
silicon required. Locally signed with the established Synora identity, not Apple
notarized. macOS may warn or request Keychain/OS permission approval locally.
Windows: run the unsigned x64 EXE installer. Security warnings may appear.
Native tool sandbox setup is still required where applicable.
Linux: install the amd64 DEB on a compatible Debian-based system.
Web: extract TAR.GZ, enter its folder, run `node start.mjs` with Node.js 22.19+
and Linux Chromium dependencies, then open the exact local URL printed.
No npm install or source checkout is needed. This is not a public hosted chat.

Keep existing user profiles when replacing the application. Full Access does
not bypass OS permissions. Verify packages with SHA256SUMS.txt.

These checks are not exhaustive certification of every external model,
plugin, OS grant or hardware. No model weights, account credentials or private
test profiles are included. Model services may require separate accounts.
